=== SUBTITLE REWRITER - HƯỚNG DẪN CHẠY ===

YÊU CẦU:
  - Python 3.10+ (cài tại https://www.python.org/downloads/)
  - BẮT BUỘC tick "Add Python to PATH" khi cài Python
  - Internet (máy phải truy cập được generativelanguage.googleapis.com)

CÁCH CHẠY:
  1. Giải nén file zip vào thư mục bất kỳ
  2. Double-click file: Start.bat
  3. Start.bat sẽ tự:
     - Kiểm tra Python có cài không
     - Tự cài dependencies nếu chưa có (flask, google-genai, ...)
     - Khởi động server
     - Mở browser tại http://localhost:5000

SỬ DỤNG:
  1. Dán Gemini API key (lấy tại: https://aistudio.google.com/apikey)
  2. (Tuỳ chọn) Gõ yêu cầu xử lý vào ô "Yêu cầu xử lý"
     VD: "Viết như đang review phim, giọng văn hài hước"
  3. Upload file video (MP4, MKV, MOV, AVI, WEBM)
  4. Upload file SRT (phụ đề)
  5. Click "Phân tích Video"
  6. Chờ xử lý (video càng dài càng lâu - 1h video ~ 2-5 phút)
  7. Click "Xem kết quả" khi xong
  8. Tải file SRT mới về

LƯU Ý:
  - Máy phải kết nối internet được với Gemini API (không bị proxy/firewall chặn)
  - Nếu báo "cannot reach this page": 
    * Kiểm tra Python có cài không (mở cmd, gõ "python --version")
    * Kiểm tra có tick "Add Python to PATH" không
    * Chạy Start.bat và đọc thông báo lỗi trên cửa sổ CMD
  - Video free tier: tối đa 2GB (paid tier: 20GB)
  - Video dài nhất xử lý được: ~3 giờ (low resolution)
  - API key KHÔNG được lưu, nhập lại mỗi lần chạy
  - Kết quả được lưu trong thư mục results/ và database instance/jobs.db
